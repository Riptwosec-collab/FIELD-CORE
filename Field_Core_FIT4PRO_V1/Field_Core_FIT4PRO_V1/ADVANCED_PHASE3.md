# FIELD CORE Advanced Phase 3

Phase 3 completes the interactive recon/mission/safety surface on top of the existing 28-feature contract.

- Dedicated Wi-Fi network list and network detail screens
- TRUST / PIN / SIGNAL HUNT / HIDE actions
- Dedicated Cyber Sweep screen
- Find Phone from Lost Mode
- Mission Pack prepare/start/stop controls
- Outdoor Scan optional location attachment (off by default)
- Context automation suggestions (never forced)
- Command Center dynamic priority ordering
- Wi-Fi 2.4 GHz adjacent-channel load weighting
- Stealth mode coupling to low-power watch presentation
- Settings controls for recon cadence, location attachment and haptics

The standard preflight workflow applies this phase deterministically and validates the resulting Fusion + Advanced contracts before committing generated source changes.
